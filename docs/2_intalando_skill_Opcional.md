# Skills

A instalação é super simples. Existem vários diretórios de skills por aí, mas eu gosto muito do **[skills.sh](https://skills.sh/)** (feito pela Vercel). Ele também mostra quantas instalações cada skill teve - o que ajuda a identificar quais skills realmente valem a pena. Podemos utilizar simplemente um `npx skills add {URL}`.

## Skill do projeto

```
npx skills add https://skills.sh/p/l0BugDdwMbjMA2j1
```
