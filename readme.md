## Dataset escolhido:
Retail Sales Dataset: Synthetic sales data for analytics and business intelligence practice.
Este conjunto de dados de vendas sintético foi criado para simular transações comerciais do mundo real e fornecer um conjunto de dados prático para projetos de aprendizagem e análise de dados. Ele contém dados de vendas em nível de transação em vários anos, cobrindo áreas como clientes, produtos, locais, canais de vendas, preços, descontos, pagamentos, receita e lucro.
URL: https://www.kaggle.com/datasets/danielsowah123/retail-sales-dataset
