# Dados

Leia arquivo `requirements/sales_data_dictionary.csv`, é uma dicionário de dados/campos.
Arquivo `data/Sales_transactions_2022_2025.csv` é um conjunto de dados de transações de vendas multicanal de varejo e B2B simulando vendas de equipamentos de escritório, eletrônicos, móveis, eletrodomésticos e suprimentos de escritório em vários canais de vendas.

Resumo da planilha:

- Período: 2022–2025
- Registros: 18.045
- Colunas: 36
- Tipo de dados: Dados de transações brutos e impuros
