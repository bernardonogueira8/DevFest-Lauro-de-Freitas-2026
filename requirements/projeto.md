# Sobre o Dataset

Este conjunto de dados de vendas sintéticas foi criado para simular transações comerciais do mundo real e fornecer um conjunto de dados prático para projetos de análise de dados de aprendizagem e construção.
Ele contém dados de vendas em nível de transação em vários anos, cobrindo áreas como clientes, produtos, locais, canais de vendas, preços, descontos, pagamentos, receita e lucro.
O conjunto de dados é adequado para Excel, SQL, Python/Pandas, Power BI, Tableau e R/RStudio.
Inspiração

Dados reais de vendas de negócios podem ser difíceis de acessar por causa da privacidade e confidencialidade. Esse conjunto de dados foi criado como uma alternativa segura para estudantes, analistas e aspirantes a profissionais de dados para praticar o trabalho com dados de negócios realistas.
Ele também inclui alguns valores ausentes, inconsistentes ou incomuns para que os usuários possam praticar a limpeza e validação de dados do mundo real.
O que você pode analisar

O conjunto de dados pode ser usado para explorar questões como:

- Como as vendas mudam com o tempo?
- Quais produtos e categorias têm melhor desempenho?
- Quais regiões geram mais receita?
- Como os descontos afetam o lucro?
- Quais canais de vendas têm melhor desempenho?
- Quais são os produtos mais rentáveis?
- Existem padrões de vendas sazonais?
- Quais áreas ou produtos estão com baixo desempenho?

Os KPIs comuns incluem Receita, Lucro, Margem de Lucro, Quantidade Vendida, Transações e Valor Médio do Pedido.
Uso

## Processos para serem analizados

Verifiquei e realize:

1. Limpeza e preparação de dados
2. Análise Exploratória de Dados (EDA)
3. Vendas e análise de clientes
4. Análise estatística
5. Painéis de inteligência de negócios

O conjunto de dados contém intencionalmente alguns problemas realistas de qualidade de dados, como valores ausentes, entradas inconsistentes e registros incomuns, tornando-o útil para demonstrar o processo de análise completo:
Dados brutos → Limpeza → Análise → Visualização → Insights → Recomendações
